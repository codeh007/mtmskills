## codex app 和 codex cli 怎么选 ?

答: 对于编程开发 首选 codex cli. 对于非编程开发(普通用户) 推荐使用codex app.

## 如何下载 codex app

打开[codex app下载地址](https://openai.com/codex/) 点击下载按默认方式安装即可.

## Windows 新用户怎么配置?

把模板目录里的三个文件放到 `%USERPROFILE%\.codex\`：

1. `config.toml`
2. `.env`
3. `auth.json`

通常只需要编辑 `.env`：

```text
OPENAI_BASE_URL="https://sub2api.yuepa8.com/v1"
OPENAI_API_BASE="https://sub2api.yuepa8.com/v1"
OPENAI_API_KEY="sk-你的api_key"
```

`config.toml` 通过 `env_key = "OPENAI_API_KEY"` 读取这个 key。不要把同一个 key 再写进 `auth.json`；`auth.json` 是 Codex 登录缓存文件，原生 OpenAI API key 登录或 ChatGPT 登录时让 Codex 自己维护。

修改 `.env` 后重启 Codex app/CLI。
